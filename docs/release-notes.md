Первый публичный тестовый выпуск **Journal 2026.1.0-alpha.2** для пробной установки и подключения существующей базы. Полный перенос старой программы ещё не завершён.

Для Windows скачайте **`Journal-2026.1.0-alpha.2-win-x64-OfflineSetup.exe`**. Он содержит приложение, модуль MDB и .NET Runtime x64/x86; интернет во время установки не нужен. Поддерживаются Windows 10 22H2 / Windows 11 x64. Можно выбрать папку установки; при установке .NET могут потребоваться права администратора. Office/Access Runtime не устанавливаются и не заменяются.

После установки откройте «База данных» и выберите **тестовую копию `OrderDB.mdb`**. Открытие списка не меняет базу; команды статуса и БЛЦБ на Windows уже записывают изменения. Старая программа и внешний файл MDB сохраняются.

Что доступно:

- Поиск, фильтры, выбор строк, цвета всей строки из БД, светлая/тёмная темы и личная компоновка.
- Результат для письма: редактирование, очистка, копирование в HTML/RTF/текст.
- Чтение существующих заявок с сохранёнными ценами; на Windows — транзакционная запись статусов и БЛЦБ с проверкой конфликтов.
- Колокольчик: тихая проверка при запуске и раз в 6 часов. Скачивание и установка с перезапуском выполняются только по команде пользователя. Без интернета журнал продолжает работать.
- **Выбор тестовых обновлений сохраняется между запусками и обновлениями.** При первом запуске тестовой установки он включён; сохранённый выбор пользователя имеет приоритет. Следующие тестовые выпуски можно получать через колокольчик.
- Чтение шести прайсов и общий расчёт по прежним правилам. На Linux — отдельная редактируемая тестовая копия реальных данных с прайсами, созданием заявок, статусами и БЛЦБ; исходная MDB там остаётся только для чтения.

Ограничения тестового выпуска:

- Создание/полное редактирование заявок в MDB, импорт спецификаций и остальные функции старой программы ещё переносятся. Прежние суммы не пересчитываются при открытии.
- Установка, MDB-хост и обновление с перезапуском проверяются в Windows CI на искусственных данных. Чистый офлайн Windows 10/11, права обычного пользователя и совместная работа по вашей общей папке ещё требуют ручного прогона. Начните с копии базы.
- AppImage требует .NET 10 и `mdbtools` отдельно. ZIP предназначен для разработки, требует среду .NET (на Windows обе разрядности) и не обновляется из программы. Обычный Velopack Setup.exe может скачивать зависимости; для первоначальной раздачи Windows предназначен **OfflineSetup.exe**.

Следующие версии появятся после публикации новых выпусков на GitHub; обычный коммит или слияние PR не создают обновление. Полный установщик повторно не нужен, пока требования к зависимостям не меняются.
