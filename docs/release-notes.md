Предварительная **сборка Journal с чтением MDB и деможурналом**. Полный перенос рабочей программы ещё не завершён.

- Через «База данных» можно подключить копию существующей `OrderDB.mdb`: поиск, фильтры и результат используют сохранённые значения. На Windows подключены транзакционная запись статусов и БЛЦБ с обнаружением конфликтов; на Linux MDB остаётся только для чтения. Ручное создание пока работает только в деможурнале текущего сеанса.
- Windows-пакет включает модуль доступа к MDB через системный Jet x86; Office/Access Runtime не устанавливаются и не заменяются. На Linux нужен `mdbtools` (`mdb-export`). Реальная общая папка и совместная запись со старой программой ещё требуют проверки.
- Перенос расчётов, создания/редактирования заявок в Access и бизнес-парсера ещё не завершён.
- Для запуска ZIP-сборок Windows нужны .NET 10 Runtime x64 и x86. Перед запуском распакуйте архив целиком. Для установки пользователям предназначен OfflineSetup.exe.
- Колокольчик сообщает о новой опубликованной версии после тихой проверки при запуске и затем раз в 6 часов. Скачивание и установка с перезапуском — вручную. Для обновления используйте установленную версию Windows/AppImage; ZIP предназначен для разработки.
- **Полный Windows OfflineSetup.exe** содержит приложение, модуль MDB и оригинальные .NET Runtime x64/x86. Интернет во время установки не нужен; совместимые среды пропускаются. При необходимости Windows запросит права на установку .NET. Старая программа, внешняя MDB и профиль сохраняются.
- Обычный Velopack Setup.exe может скачать среды из сети. AppImage требует .NET 10 и mdbtools отдельно. Чистый офлайн Windows 10/11, UAC обычного пользователя и рабочую общую папку нужно проверить перед массовой раздачей.
- Открытие/обновление списка не меняет базу и не пересчитывает цены. На Windows выбранные статусы и БЛЦБ записываются в подключённую MDB; для разработки используйте копию.

Процесс выпуска создаёт **черновик** для проверки. Перед публикацией рабочего выпуска необходимо проверить реальные сценарии на Windows и готовый установщик.
