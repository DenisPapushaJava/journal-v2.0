Тестовый выпуск **Journal 2026.1.0-alpha.3** для проверки обновления с `2026.1.0-alpha.2` через колокольчик. Полный перенос старой программы ещё не завершён.

Что нового:

- В окне колокольчика появился переключатель **«Проверять обновления автоматически»**. Выбор сохраняется между запусками. Отключение останавливает фоновую проверку; ручная кнопка остаётся доступной. При включении программа снова проверяет GitHub при запуске и раз в 6 часов. Скачивание и установка всегда по вашей команде.
- Полный Windows-установщик заранее объясняет, почему пользовательская установка недоступна в Program Files и каталоге Windows, и сохраняет лог. По умолчанию используется папка в профиле пользователя; можно выбрать другую доступную папку.
- Добавлены локальная диагностика блокировок Windows и MIT-лицензия проекта. **Собственные EXE пока не подписаны Authenticode**; этот выпуск не обещает устранить корпоративные ограничения запуска.

Если `alpha.2` уже установлена, повторная установка OfflineSetup не требуется. Откройте **колокольчик → «Получать тестовые версии» → «Проверить обновления» → «Скачать» → «Установить и перезапустить»**. После перезапуска в окне обновлений должна быть текущая версия `2026.1.0-alpha.3` и новый переключатель автопроверки. Проверьте сохранение пути к базе, личной компоновки и текста результата. [Подробный сценарий проверки](https://github.com/DenisPapushaJava/journal-v2.0/blob/main/docs/update-pilot.md).

Для нового Windows-компьютера скачайте **`Journal-2026.1.0-alpha.3-win-x64-OfflineSetup.exe`**. Он содержит приложение, модуль MDB и .NET Runtime x64/x86; интернет во время установки не нужен. Поддерживаются Windows 10 22H2 / Windows 11 x64. При установке .NET могут потребоваться права администратора. Office/Access Runtime не устанавливаются и не заменяются. Требования к зависимостям по сравнению с `alpha.2` не изменились.

Существующая внешняя `OrderDB.mdb` не заменяется и не конвертируется при обновлении. Для первого подключения используйте копию: команды статуса и БЛЦБ на Windows уже записывают изменения. Создание/полное редактирование заявок в MDB, импорт спецификаций и остальные функции старой программы ещё переносятся; прежние суммы при открытии не пересчитываются.

Установка, MDB-хост и обновление с перезапуском проверяются в Windows CI на искусственных данных. Реальное обновление на рабочем Windows 11, чистая офлайн-установка и совместная работа по вашей общей папке требуют ручного прогона. AppImage требует .NET 10 и `mdbtools` отдельно. ZIP предназначен для разработки и не обновляется из программы.
