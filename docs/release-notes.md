Тестовый выпуск **Journal 2026.1.0-alpha.5**: импорт HTML/PDF, редактирование заявок, локальная корзина и подготовка текста для письма.

Что нового по сравнению с alpha.4:

- **Импорт спецификаций HTML БЛОК/Wintech и PDF HansLaser.** Перетащите один файл на журнал или нажмите «Выбрать спецификацию» в новой заявке. Распознанные поля открываются для проверки; сохранение выполняется отдельно пользователем. Номер и дата берутся из заголовка/номера заказа внутри документа, дата формирования PDF и внешнее имя файла их не подменяют. Пропуски и найденные противоречия показаны явно; неизвестный ID HansLaser требует ручной проверки до расчёта цены.
- **Редактирование и корзина.** При сохранении правок цена пересчитывается по текущему прайсу с проверкой конфликтов. Можно отправлять в корзину несколько выбранных заявок и восстанавливать их. Копии хранятся 30 дней локально на этом компьютере в профиле пользователя; это не общая резервная копия MDB.
- **Компактные формы новой заявки и редактирования.** Две равные колонки, подписи возле полей, ограничение размера окна рабочей областью монитора. Из спецификаций количество листов заполняется целым итогом; вручную можно указать одно число, включая дробное. Выражения и слова при новом вводе отклоняются, исторические значения базы не исправляются автоматически.
- **Текст для письма.** Компактная серая область с круглыми кнопками и растягиванием. Размеры 8/10/12/14 pt и палитра цветов сохраняются локально; начальные Arial 10 pt и мягкий красный. Копирование передаёт HTML, RTF и обычный текст. Каждая добавляемая порция идёт по толщине, затем материалу; состав строк и ручные правки накопленного текста сохранены.
- **Заставка с логотипом и текущей версией** остаётся минимум две секунды и до завершения первой загрузки заявок.
- **Понятная диагностика блокировки MDB-компонента Windows.** Приложение и полный установщик объясняют отказ запуска/подписи AccessHost и предлагают открыть настройки безопасности. Защита Windows автоматически не меняется.

Схема и прежние поля `OrderDB.mdb` сохраняются. Правила длины и коэффициента перенесены из старой программы; исторические цены не пересчитываются при чтении. Локально импорт сверён с 31 HTML и 60 PDF HansLaser; реальные документы и базы не включены в выпуск.

**Первую проверку нового импорта, редактирования и восстановления выполняйте на отдельной копии `OrderDB.mdb`.** Проверьте результат в старой программе. Работа двух клиентов через общую папку, потеря сети и нативное перетаскивание файлов требуют проверки в вашем окружении. [Импорт PDF HansLaser](https://github.com/DenisPapushaJava/journal-v2.0/blob/main/docs/hans-pdf-import.md), [HTML](https://github.com/DenisPapushaJava/journal-v2.0/blob/main/docs/specification-import.md), [редактирование и корзина](https://github.com/DenisPapushaJava/journal-v2.0/blob/main/docs/order-maintenance.md).

Обновление установленной alpha-версии: **колокольчик → «Получать тестовые версии» → «Проверить обновления» → «Скачать» → «Установить и перезапустить»**. Повторный полный установщик не нужен: зависимости не изменились.

Для первой установки Windows — **`Journal-2026.1.0-alpha.5-win-x64-OfflineSetup.exe`** со средами .NET 10 x64/x86 и модулем MDB x86. Office/Access Runtime не переустанавливаются. **Доверенная подпись SignPath ещё не получена; собственные EXE остаются неподписанными. Smart App Control или корпоративная политика могут блокировать приложение/AccessHost; этот выпуск блокировку не снимает.**

Ограничения: вставка текста из буфера и OCR, пакетный импорт, перенос старого конфига, комментарии, создание папок и произвольный цвет ещё не подключены. `TechnologColor` автоматически не переносится. На Linux исходная MDB остаётся только для чтения; полноценная работа доступна в отдельной локальной копии без обратной записи в MDB. AppImage требует .NET 10 и `mdbtools` отдельно. ZIP предназначен для разработки и не обновляется из программы.
