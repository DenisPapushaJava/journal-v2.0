Предварительная **сборка Journal с чтением MDB и деможурналом**. Полный перенос рабочей программы ещё не завершён.

- Через «База данных» можно подключить копию существующей `OrderDB.mdb` только для чтения: поиск, фильтры и результат используют сохранённые значения. Создание, статусы и БЛЦБ пока работают только в деможурнале текущего сеанса.
- Для чтения на Windows нужен совместимый ACE той же разрядности, что приложение; на Linux — `mdbtools` (`mdb-export`). Реальная общая папка и совместная запись ещё не проверены.
- Перенос расчётов, записи в Access и бизнес-парсера ещё не завершён.
- Для запуска ZIP-сборок нужна совместимая .NET 10 Runtime. Перед запуском распакуйте архив целиком.
- Офлайн-установщик Windows со всеми необходимыми компонентами ещё не реализован.
- Эти сборки не изменяют существующий `OrderDB.mdb`.

Процесс выпуска создаёт **черновик** для проверки. Перед публикацией рабочего выпуска необходимо проверить реальные сценарии на Windows и готовый установщик.
