Тестовый выпуск **Journal 2026.1.0-alpha.4**: создание заявки с расчётом и сохранением в существующую MDB на Windows.

Что нового:

- **«Новая заявка» работает с подключённой MDB.** Форма сохраняет введённые поля, актуальную цену и совместимый коэффициент; номер записи выделяет Access. Исторические строки и схема базы не меняются.
- **Предварительный расчёт** доступен на Windows и в локальной Linux-копии. Видны цена и расшифровка «тариф × метры × коэффициент». Сохранение повторно проверяет тариф: если просмотренная цена изменилась, сначала покажет новую сумму и дождётся следующего ручного нажатия.
- При обычной ошибке записи введённые поля остаются в форме. При неподтверждённом сохранении повтор блокируется: нужно закрыть форму, выполнить F5 и проверить, не появилась ли заявка. Следующее открытие «Новая заявка» восстановит ввод в текущем сеансе. Автоматического повторного добавления нет.
- После успешного добавления новая строка видима и выбрана; подготовленный результат для письма сохраняется. На время записи блокируются операции журнала и закрытие приложения.

**Первую проверку выполняйте на отдельной копии `OrderDB.mdb`.** Создайте заявку, выполните F5, откройте ту же копию старой программой и проверьте поля/цену. Совместную сетевую работу и потерю связи ещё нужно проверить в вашем окружении. [Подробный сценарий](https://github.com/DenisPapushaJava/journal-v2.0/blob/main/docs/manual-orders.md).

Ограничения: полное редактирование, удаление, импорт спецификаций и перенос прежнего конфига ещё предстоят. Начальный цвет новой заявки пока `-1`; `TechnologColor` из старого конфига автоматически не переносится. На Linux сама MDB остаётся только для чтения, редактируемый режим использует отдельную локальную копию без обратной записи в MDB.

Обновление установленной `alpha.2`/`alpha.3`: **колокольчик → «Получать тестовые версии» → «Проверить обновления» → «Скачать» → «Установить и перезапустить»**. Повторный полный установщик не нужен: зависимости не изменились.

Для нового Windows-компьютера — **`Journal-2026.1.0-alpha.4-win-x64-OfflineSetup.exe`**, содержащий приложение, модуль MDB x86 и .NET Runtime x64/x86. Office/Access Runtime не переустанавливаются. Собственные EXE пока без Authenticode; ограничения корпоративной политики запуска этим выпуском не отменяются. AppImage требует .NET 10 и `mdbtools` отдельно; ZIP предназначен для разработки и не обновляется из программы.
