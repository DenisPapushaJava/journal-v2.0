# Контекстные меню

Локальный этап UX-63, 18.10.2026. Меню дополняют видимые команды; существующие кнопки остаются. Новых операций с MDB и изменений её схемы нет.

## Выбор и вызов

- ПКМ по выбранной строке журнала сохраняет весь набор, по другой строке выбирает только её. Заголовок меню показывает номер спецификации или «Выбрано: N».
- Shift+F10 и клавиша Menu открывают то же меню с клавиатуры. Оно располагается у выбранной видимой строки; Escape закрывает его и возвращает фокус таблице.
- ПКМ по пустой области предлагает только «Новая заявка» и «Обновить». Эти команды не используют ранее выбранный набор.
- Заголовок столбца открывает отдельное меню; открытие само по себе не сортирует и не снимает выбор.
- При смене выбора, фильтров, источника или доступности операций старое меню закрывается. Обработчики дополнительно проверяют версию контекста и набор ID. До открытия диалога меню закрывается.

## Строки журнала

| Группа | Команды |
| --- | --- |
| Заявки | Редактировать; Добавить БЛЦБ |
| Подготовка | Сформировать результат; Скопировать комментарий строки; Скопировать задание на резку; Создать папки |
| Отметки | Одно подменю «Статус и цвет»: В работе, Готово, Отгружено, Мой цвет (если включён), Цвет, Снять цвет |
| Выбор | Снять выбор |
| Удаление | В корзину — с количеством для набора |

Редактирование и комментарий строки доступны для одной заявки. Результат, БЛЦБ, задание на резку, папки, статус/цвет и корзина работают с выбранным набором и прежними проверками. Снятие цвета и снятие выбора — разные действия. Проверка общего БЛЦБ, подтверждения корзины, конфликты и запрет повторной записи при неизвестном исходе сохранены. Источник только для чтения и режим настройки экрана сохраняют ограничения видимых кнопок.

23.10.2026: «Мой цвет» с образцом появляется перед «Цвет…», только если
включено «Использовать свой цвет» и сохранён допустимый личный цвет. Применяет
его ко всему выбранному набору штатной командой изменения цвета с прежней
проверкой конфликтов/F5. Меню перечитывает настройку при каждом открытии;
устаревший пункт после смены цвета или отключения настройки не выполняется.
Профиль, схема MDB и правило окраски новых заявок не меняются. Локально без
коммитов/push/PR/релиза.

## Заголовки

«По возрастанию», «По убыванию», «Стандартный порядок», «Фильтр» при его наличии, «Скрыть столбец». Явное направление заменяет цепочку сортировки одним столбцом независимо от Shift/Ctrl; обычный трёхпозиционный клик заголовка не меняется. Стандарт остаётся датой/числовым номером/кодом; по UX-64 ASC для выбранного дня и DESC для истории. Расширение состава меню после UX-63 отложено пользователем. Видимость сохраняется прежним механизмом компоновки. Первая служебная колонка защищена: только «Настроить таблицу».

## Текст результата и корзина

Результат: отменить ввод, вырезать, копировать выделенный текст, вставить, выделить всё; отдельно **«Копировать для письма»** и «Очистить результат». Копирование для письма использует весь текущий текст с ручными правками в text/HTML/RTF, без нового формирования по заявкам. HTML всегда состоит из редактируемых строк без таблицы и изображений; обычное копирование выделения не меняется. Очистка не снимает выбор таблицы. Остальные поля ввода сохраняют штатные текстовые меню Avalonia.

Корзина: ПКМ выбирает конкретную копию; «Восстановить» и «Удалить окончательно» открывают прежние подтверждения. Для Pending/занятой или требующей обновления корзины действия недоступны. «Очистить корзину» остаётся общей кнопкой в шапке и не включается в меню строки.

## Проверка и границы

Синтетические данные, Avalonia Headless на Linux: мышь/клавиатура, сохранение набора, отмена, одиночный редактор, массовый статус, подтверждения удаления/восстановления, защита Pending, устаревших пунктов и режима только чтения, сортировка/фильтры/защищённая колонка, форматы буфера и ручные правки. Обе темы и масштаб 100/150% при 1280×720; снимки просмотрены. Настоящая Windows, системный скринридер и несколько мониторов требуют отдельного прогона. Figma не менялась.

Итоговая проверка UX-63: scripts/check.sh прошёл; Release без предупреждений/ошибок, 1169 успешных тестов (включая 12 новых сценариев меню), 16 необязательных пропусков и 20 Python-проверок. Все 67 нативных Access-проверок на Linux пропущены; Windows/Jet/SMB этим прогоном не подтверждены.
