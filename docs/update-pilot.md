# Проверка обновления на Windows

Сценарий: на другом компьютере установлена **2026.1.0-alpha.2**, после публикации **2026.1.0-alpha.3** она получает обновление через колокольчик. Это проверка установленного приложения и публичного GitHub, а не повторная установка поверх старой версии.

## До обновления

1. Запустите Journal обычным ярлыком из установленной `alpha.2`. Откройте колокольчик и запишите «Текущая версия». ZIP/F5-сборка не подходит: окно в ней объясняет, как установить обновляемое приложение.
2. Для проверки данных выберите тестовую копию `OrderDB.mdb` вне папки установки. Запомните её путь, тему и любую изменённую ширину столбца. В «Результат» введите, например, «Проверка обновления alpha.2 → alpha.3».
3. Закройте другие окна Journal этой же установки и завершите операции с базой. Для этого сценария не нужно изменять статусы или БЛЦБ.

## Найти, скачать, применить

1. Нужен доступ к GitHub и загрузке его файлов. В колокольчике включите **«Получать тестовые версии»**, затем **«Проверить обновления»**. Ждать 6 часов не нужно. При фоновом обнаружении на колокольчике появляется цветная точка, подсказка называет новую версию.
2. Ожидаемый результат: предложена **2026.1.0-alpha.3**, видны её изменения. Пока не нажата «Скачать», пакет не загружается.
3. Нажмите **«Скачать»**, дождитесь окончания. Journal остаётся открыт; перезапуск ещё не начался.
4. Нажмите **«Установить и перезапустить»**. Дождитесь самостоятельного запуска приложения; не устанавливайте новый OfflineSetup между этими шагами — иначе будет проверен другой сценарий.

## После перезапуска

- В колокольчике **текущая версия 2026.1.0-alpha.3** и новый переключатель **«Проверять обновления автоматически»**. Это видимое отличие от `alpha.2`.
- Сохранились путь к внешней MDB, тема, ширина столбца и точный текст результата. Исходная база остаётся на своём месте.
- «Получать тестовые версии» остаётся включено. Повторная проверка сообщает, что новых версий в выбранном канале нет; отметка на колокольчике исчезла.
- Отключите автопроверку, закройте и снова откройте Journal обычным ярлыком. Переключатель остаётся выключен; ручная проверка работает. Затем верните удобный для вас режим.

Успешным результатом считается весь путь **alpha.2 → обнаружение → ручная загрузка → перезапуск → alpha.3 с сохранённым профилем и результатом**. Запишите версии до/после и результат этих пунктов. Одно появление новой версии ещё не доказывает установку.

## Если не получилось

- Новая версия не найдена: проверьте текущую версию, галочку тестового канала и [публикацию alpha.3](https://github.com/DenisPapushaJava/journal-v2.0/releases/tag/v2026.1.0-alpha.3). Только опубликованный выпуск с feed и пакетом становится обновлением; тег/черновик не подходят.
- Ошибка сети/скачивания: сохраните точный текст из окна и повторите проверку при доступном GitHub. Текущая версия остаётся доступной.
- Сообщение о незавершённых операциях: закройте формы/другой экземпляр и дождитесь завершения работы с базой. MDB внутри папки установки сначала нужно разместить вне неё и подключить оттуда.
- Windows блокирует запуск: сохраните точный текст и соберите [локальный диагностический отчёт](windows-signing.md). В `alpha.3` собственный код также пока без Authenticode; первоначальная причина блокировки на рабочем ПК не подтверждена. Не отключайте корпоративную защиту для проверки.

## Что проверяется до раздачи

Release CI на Windows проверяет OfflineSetup, установленный хост x64 → Jet x86 и цикл обновления с перезапуском отдельной `UpdateProbe` на искусственных данных. После публикации публичный feed проверяется настоящим адаптером и моделью окна колокольчика, включая загрузку Windows-пакета, готовность к ручной установке и отсутствие повторного предложения той же версии:

```bash
./scripts/dotnet.sh run --project tests/Fixtures/UpdateProbe -- --check-published-release 2026.1.0-alpha.3 2026.1.0-alpha.2
```

Этот вызов использует временный тестовый locator, удаляет скачанный пакет и не запускает Windows-код. Он не заменяет описанный выше прогон на компьютере пользователя с его сетевыми правами и политиками Windows.
