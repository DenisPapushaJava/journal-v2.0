# Фильтры таблицы — UX-55/56

Локальная реализация 18.10.2026, без push/PR/релиза. Меню с воронкой находится в заголовках «Менеджер», «Вид резки», «Материал», «Толщ., мм», «Гибка» и «Статус». Четыре прежние кнопки статуса над таблицей заменены меню; дата/«Сегодня», поиск и общий «Сбросить» остаются в одной строке. Поиск сжимается по ширине и не переносится.

По последнему уточнению пользователя фильтр заказчика исключён: остаются столбец и обычный поиск по заказчику, без построения большого списка вариантов.

## Выбор и применение

В меню — чекбоксы, «Все» с промежуточным состоянием, «Применить» и «Очистить фильтр». Хотя бы одно значение должно быть выбрано. Изменения черновика не влияют на таблицу до применения; Escape и клик снаружи отменяют их. Текст заголовка сортирует, воронка открывает меню без сортировки. Занятый журнал, смена контекста/источника/личного цвета закрывают открытый черновик.

Значения одного столбца объединяются по **ИЛИ**, столбцы, статус, дата и поиск — по **И**. Меню строится по загруженному снимку, с учётом всех ограничений **кроме собственного столбца**: можно расширить его выбор. Число справа — количество подходящих заявок. Выбранные значения без совпадений/исчезнувшие после F5 остаются с нулём, чтобы их можно было снять; ограничения не сбрасываются автоматически и не заменяются другими значениями.

В пяти новых меню есть поиск по значениям без учёта регистра: он только скрывает пункты меню, не сбрасывая отмеченные вне поиска. «Все» относится ко всему текущему списку, а не только результатам поиска. Явное включение «Все» снимает ограничение столбца; выбор конкретного единственного доступного значения может закрепить его при последующем снятии соседних фильтров. Применение неизменённого черновика сохраняет прежний набор. Полный выбор всего глобального набора равнозначен отсутствию ограничения.

Текстовые значения группируются без учёта регистра и крайних пробелов; разные марки/названия не склеиваются по похожести. Это только сравнение фильтра, данные не изменяются. Пустые значения — «(Пусто)». Толщины сравниваются как decimal, сортируются численно, выводятся с запятой; неизвестная толщина — отдельное пустое значение. Длинный список имеет ограниченную высоту и общую узкую полосу прокрутки. Длинные названия обрезаются с подсказкой полного текста; подсказки ограничены по ширине и переносятся.

Гибка: «Есть», «Нет», «Неизвестно». Последнее включает недоступные и требующие повторной проверки пометки, отображаемые в строке как «?». Не считать их отсутствием гибки. Отсутствие отдельной пометки при доступных данных по прежнему контракту означает «Нет».

## Обратная связь и сброс

Активные воронки выделяются акцентом. Компактные отметки с крестиками находятся **под строкой поиска**, при необходимости переносятся, оставляя сам поиск в одной строке. Одна отметка снимает только свой столбец; она доступна при скрытом столбце/горизонтальной прокрутке. Общий «Сбросить» очищает все шесть фильтров, поиск/его область и дату.

Применение изменившегося фильтра очищает выбор заявок; неизменённый черновик, отмена и сортировка сохраняют выбор. Готовый результат для письма не меняется. F5/редактирование/массовая смена статуса используют те же ограничения и обновляют доступные варианты при следующем открытии меню. После создания новых заявок прежнее поведение сохраняется: ограничения сбрасываются, чтобы показать сохранённые строки. Смена источника также сбрасывает фильтры.

## Статус и личный цвет

Без включённой персональной окраски: «Без статуса», «В работе», «Готово», «Отгружено». При включённом «Использовать свой цвет»: **«Мои заявки»** с образцом цвета, «Другие без статуса» и три рабочих статуса. Название выбрано пользователем; «Мой цвет»/«Мои по цвету» не использовать. Статусные категории сохраняются в меню даже при нулевом количестве.

Три рабочих статуса определяются прежними точными кодами Orders.Color. «Мои заявки» — точным совпадением с текущим допустимым персональным ARGB; остальные цвета/NULL/−1 относятся к «Другие без статуса». Без включённого личного цвета все такие строки относятся к «Без статуса». Категории не перекрываются. Смена статуса/цвета может убрать строку из текущего фильтра; отдельной истории авторства нет.

При включении личного цвета выбранное «Без статуса» разделяется на обе новые категории без потери строк. При отключении «Мои заявки» удаляются из выбора; оставшиеся категории сохраняются, выбор только «Мои заявки» сбрасывается на «Все». Поиск, дата и остальные столбцы сохраняются. Недопустимый промежуточный ввод цвета не меняет принятое значение.

## Устройство и границы

Фильтры остаются состоянием сеанса, не записывают MDB/JSON-копию, не меняют расчёты и форматы письма. Все существующие имена/ключи столбцов сохранены через HeaderTemplate. Меню/черновики — Controls/ColumnFilterHeader, StatusFilterHeader и соответствующие ViewModels; единый предикат — MainWindowViewModel.ColumnFilters/StatusFilter/Batch. Обновление списка не выполняет новых запросов к БД для каждого меню.

Ширина таблицы уточнена в [screen-layout.md](screen-layout.md): компактные минимумы под Full HD, автоматические относительные размеры, однократное обновление старых профилей и сохранение последующих ручных размеров. Настройки ширины/порядка/видимости остаются локальными, фильтры их не сбрасывают.

Проверки используют синтетические данные и Avalonia Headless. Настоящая Windows, системный скринридер и работа на нескольких мониторах требуют отдельного прогона; рабочая MDB не использовалась. Figma в этом этапе не менялась.

Проверка этапа: окончательные 54 целевых теста (34 новых + 20 прежних) прошли, Debug/Release собираются без предупреждений. Проверены обе темы, минимальное окно 1280×680, DPI 100/150%, длинные списки, сочетания/отмена/сброс и сохранение ширин. Снимки просмотрены. Общий scripts/check.sh перед заключительным уточнением малого decimal и двумя дополнительными тестами профиля: 1035 успешных/16 пропусков и 20 Python-проверок; затем повторены все 54 целевых сценария. 66 отдельных нативных Access-проверок на Linux пропущены.
