# Импорт спецификаций ГАР AWJC

Локальная реализация 17.10.2026, ещё не опубликована. Профиль `waterjet-awjc/v1` добавлен в общий SpecificationProfileCatalog; HTML БЛОК/HansLaser используют прежние профили. Доступны одиночный/пакетный DnD, выбор файлов и замена спецификации в редакторе. Новых отдельных путей сохранения/кнопок импорта нет.

## Что подтверждено пользователем

- Номер и дата — строго из внутреннего заголовка с именем раскроя, не из внешнего имени файла и не из даты формирования PDF.
- Длина в миллиметрах переводится в целые метры вверх: 161253 → 162.
- Физический размер листа — «Раскрой», количество — «Количество листов». «Общий раскрой» описывает весь холст; для нескольких листов его размер не записывается как размер листа.
- Длина и «Общий вес» уже итоги документа. Их нельзя ещё раз умножать на число листов.
- Правдоподобный материал подставляется с заметной проверкой: пользователь подтверждает галочкой или исправляет текст. До этого сохранение позиции/включённого пакета недоступно. Замена файла требует новой проверки. Пробелы в материале допускаются только для станка с этим профилем; прежние ограничения БЛОК/HansLaser не расширяются.
- Время — часы:минуты, секунды вверх до минуты. Часы могут превышать сутки/неделю.

## Как извлекаются поля

Распознавание требует внутреннего `--AWJC`, раздела «Резка Материал» и набора подписей итогов. Профиль работает по координатам слов/строк и границам ячеек с масштабируемым допуском. Порядок PDF-объектов, внешний путь и имена деталей не выбирают значения. Неподходящий PDF отклоняется; известный неполный документ открывается с пустыми/отмеченными полями. Несколько итоговых раскроев в одном PDF требуют разделения, первая страница автоматически не выбирается.

Из внутреннего имени извлекаются дата и номер, допустимы один/два дефиса перед номером; journal-номер MMdd-NNN[N]. Материал берётся из строки «Материал» в шапке: категория, толщина, возможная марка. Видимые FreeText-пометки PDF рядом с этой ячейкой могут содержать конкретную марку; конфликтующие марки оставляют поле пустым. Пометки вне ячейки/невидимые/с повреждённой геометрией не используются. DocumentReader хранит их отдельно от основного текста, поэтому они не перемешиваются со словами прежнего HansLaser-профиля. Есть ограничения числа/длины пометок.

Длина — «Длинна реза» / «Длина реза», толщина из итогового блока сверяется с материалом, размер из «Раскрой», количество из двух строк «Количество листов», вес из «Общий вес». Для длительности поддержаны HHH:MM:SS и D.HH:MM:SS (дни отдельно), необязательное значение десятичных часов в скобках не участвует в расчёте. Неверные числа, расхождения и пропуски диагностируются с исходной страницей/областью/текстом; сканы без текстового слоя не распознаются через OCR.

В поле, таблице и результате длительность выводится в общих часах и минутах, секунды округляются вверх: `00:01:22` → `00:02`, `6.00:19:41` → `144:20`, `3.11:37:29` → `83:38`. Часы не сбрасываются при переходе через сутки; ровная минута повторно не округляется.

Пробивки/детали не переносятся из неоднозначных колонок деталей как общие итоги. Коэффициент начально 1, редактируемый; лазерная надбавка по пробивкам для ГАР не применяется. Цена — тариф за метр по толщине из прайса выбранного станка.

Автовыбор станка допустим при одном станке с AWJC-профилем или если пользователь уже выбрал соответствующий станок. При нескольких привязках поле оставляется для выбора. Сохранение AWJC с выбранным старым лазером/другим профилем блокируется. В редакторе прежние газ/ID/детали не переносятся в новый профиль по fallback; diff показывает изменения и очищение. MDB хранит прежние поля и дополнительную длительность по [контракту времени](cutting-time.md), а каталог станков — по [контракту прайсов](pricing.md#создание-станка-и-общий-каталог--ux-47).

Исправление 18.10.2026: одиночный DnD на главное окно сначала загружает каталог текущей базы, затем связывает станок и заполняет форму. Прежде привязка происходила с пустым каталогом, а загрузка после открытия окна не повторяла выбор. Оверлей остаётся занят до завершения чтения каталога; отмена не открывает частично подготовленную форму. Отсутствие подходящего станка или несколько совпадений по-прежнему требуют ручного выбора.

## Проверки и границы

25 частных PDF из предоставленной папки сверены с независимым извлечением Poppler: внутренние номера/даты, материал с пометками, размеры отдельных листов, количества, итоги и длительность, включая 3/4 листа и длительность в днях. SHA-256 исходников не изменились. Манифест задаётся JOURNAL_WATERJET_SPEC_MANIFEST; реальные PDF/поля/хеши хранятся только вне Git. Публичные синтетические тесты проверяют масштаб/порядок слов, чужие PDF, частичный документ, конфликт материала и подтверждение в обеих темах. Рабочая MDB/пользовательский JSON не менялись. Linux/Headless не заменяют нативную запись Jet, старый EXE и общий SMB-файл.
